PengBASIC is Microsoft 8K BASIC with most of Extended and some of QuickBASIC on top. A program from BASIC Computer Games (1978) should run as printed. Where a behavior has been checked against a real GW-BASIC or QuickBASIC 4.5 it is marked ✓.

Getting started

A line beginning with a number is stored. Anything else runs at once. 

10 PRINT "HELLO"
20 GOTO 10
RUN

STOP or Ctrl+C interrupts; CONT resumes. LIST shows the program, NEW throws it away. Paste a whole listing in and it types itself; DOWNLOAD saves one and UPLOAD reads one back.

Lines and editing

A line is kept exactly as typed, spacing and indentation included, and LIST gives it back the same way. Several statements fit on one line separated by :.

LIST [n][-[m]] Show the program, or a range. Pauses every screenful; Ctrl+C stops it.
DELETE n[-m] Remove lines. A bare DELETE is refused.
RENUM [new][,old][,step] Renumber, rewriting every GOTO, GOSUB, THEN and RESTORE that pointed at a moved line.
AUTO [start][,step] Offer line numbers as you type. Ctrl+C leaves.
EDIT [n] Fetch a line back to the prompt. Bare EDIT fetches whichever line last failed.
NEW Erase the program and everything it made.
RUN [n] Start, optionally at a line. Clears variables and restarts the random sequence.
CONT Carry on after STOP or Ctrl+C.
TRON / TROFF Print each line number as it runs, or stop doing so.
HELP [topic] This manual. HELP PRINT opens one entry.

Numbers

Four types, chosen by a suffix on the name or by DEFINT and friends.

Suffix Type Holds
% integer −32768 to 32767
! or none single about 7 digits
# double about 16 digits
$ string up to 255 characters

Single precision is a real 32-bit float and rounds like one, at every step. ✓ This is not a defect: 

10 PRINT 1/3            ' .3333333
20 S=0: FOR I=1 TO 10: S=S+.1: NEXT
30 PRINT S, S=1       ' 1 and 0 -- prints as one, is not one

How a constant is written decides its type: 1.5 is single, 1.5# and 1D10 are double, and so is anything with more than seven digits. Printing follows: seven digits and E for a single, sixteen and D for a double.

DEFINT / DEFSNG / DEFDBL / DEFSTR letter[-letter] Give a range of initial letters a default type. DEFINT A-Z opens many listings.

Strings

Joined with +, compared by character code, up to 255 long. Characters are CP437, not Latin-1, so CHR$(176) is a shade block and CHR$(218) a box corner. MID$ also assigns: 

10 A$="PENGER": MID$(A$,2,3)="XYZ": PRINT A$   ' PXYZER

Operators

Tightest first. Every one groups left to right. ✓

^ Power. 2^3^2 is 64, not 512 — left to right, unlike mathematics. ✓
- (unary) Negate. Binds looser than ^: -2^2 is −4.
* / Multiply, divide.
+ - Add, subtract. + also joins strings.
= <> < > <= >= Compare. The answer is a number: −1 true, 0 false.
NOT Bitwise complement of a 16-bit integer.
AND OR Bitwise, not logical — which is why true is −1, with every bit set.

Statements

Printing and asking

PRINT [items]

; joins, , moves to the next 14-column zone, and either at the end holds the line open. TAB(n) and SPC(n) place things. Every number prints with a leading sign position and a trailing space, which is why columns line up on their own. ? is short for PRINT.

PRINT USING format$; items

Formatted output. ✓ # a digit, . the point, , groups thousands, + or - a sign, $$ a floating currency sign, ** asterisk fill, **$ both, ^^^^ an exponent. For strings: ! one character, \  \ a fixed width, & the whole thing. _ quotes the next character. A number too wide for its field is printed in full behind a % rather than quietly truncated. 

PRINT USING "##,###.##"; 1234.5     '  1,234.50
PRINT USING "##.##^^^^"; 1234      '  1.23E+03
INPUT ["prompt";] variables

Ask and assign. ; after the prompt adds ? ; , adds nothing at all. Anything wrong with the answer — too few values, too many, or the wrong kind — gives ?REDO FROM START and asks again from the beginning. ✓ An empty line is zero.

LINE INPUT ["prompt";] string$

Take the whole line, commas and spaces and all. How you read a name like SMITH, JOHN.

DATA items · READ variables · RESTORE [line]

Constants carried in the program. READ walks them in order wherever they sit; RESTORE goes back to the start, or to a line. DATA ends at a colon. ✓

Choosing

IF test THEN ... [ELSE ...]

A number after THEN means GOTO. With nothing after THEN it is a block, closed by END IF and with any number of ELSEIF arms. 

10 IF S>=90 THEN
20   PRINT "EXCELLENT"
30 ELSEIF S>=70 THEN
40   PRINT "GOOD"
50 ELSE
60   PRINT "POOR"
70 END IF
SELECT CASE value

Arms are CASE with a value, a list, a range (CASE 70 TO 89) or a comparison (CASE IS >= 90), plus an optional CASE ELSE, closed by END SELECT. Exactly one arm runs; the value is worked out once.

ON n GOTO/GOSUB lines

A jump table: 1 takes the first line, 2 the second.

Repeating

FOR v=a TO b [STEP s] … NEXT [v[,v]]

The limit is tested before the body, so FOR I=1 TO 0 runs nothing and leaves I as 1. ✓ EXIT FOR leaves early, with the counter where it stood.

WHILE test … WEND

Test at the top. May run no times.

DO [WHILE/UNTIL test] … LOOP [WHILE/UNTIL test]

Put the test at either end, not both. At the top it may run no times; at the bottom it always runs once. EXIT DO leaves.

GOSUB line … RETURN

A subroutine. Variables are shared — there are no locals and no parameters.

GOTO line

Go there.

END · STOP

END finishes. STOP finishes and says where, so CONT can carry on.

Variables and arrays

[LET] variable = value

LET is optional and nobody writes it.

DIM name(bounds) · REDIM · ERASE

Bounds are inclusive upper bounds counting from 0, so DIM A(10) makes eleven. An array used without DIM gets 0–10. ERASE throws one away; REDIM does both at once. A scalar A and an array A() are different variables.

OPTION BASE 0|1

Move the first subscript. Must come before any array exists.

CONST name = value

A name that cannot be assigned to.

DEF FNname(args) = expression

A function of your own, one expression long. Parameters are borrowed and put back, so a global of the same name survives.

SWAP a, b

Exchange two variables.

CLEAR [n][,m]

Forget every variable. The numbers set string and stack space on a real machine; here they are read and discarded.

The screen

CLS

Clear the screen and go home.

LOCATE [row][,col][,cursor]

Move the cursor, counting from 1. The third argument shows or hides it.

COLOR [foreground][,background]

See Colors.

DELAY milliseconds

Wait. Not a Microsoft statement: this machine is far faster than the ones these listings were written for, so a FOR I=1 TO 500: NEXT pause finishes instantly and anything meant to be watched needs a real one.

Trouble

ON ERROR GOTO line

Send errors to a handler instead of stopping. ON ERROR GOTO 0 stops trapping — and inside a handler it re-reports the error being handled, which is how a program says "not mine".

RESUME [NEXT|line]

Leave the handler: retry the statement that failed, step past it, or go somewhere. Statements, not lines — RESUME NEXT lands on the next statement even if it is on the same line. Trapping is suspended while a handler runs, so a mistake in one is reported rather than looping.

ERROR n · ERR · ERL

Raise an error deliberately; report the code and line of the last one. See Errors.

Elsewhere

RANDOMIZE [seed]

Seed the generator. With no seed it stops and asks. ✓ RUN restarts the sequence, so a program that never seeds deals the same cards every time — which is why listings open with this.

DOWNLOAD ["name"] · UPLOAD

Save the program as a file, or read one back after clearing. Ours, not Microsoft's: this machine has a host rather than a disk.

REM text · ' text

A comment, to the end of the line.

Functions

ABS(n) Magnitude.
SGN(n) −1, 0 or 1.
INT(n) Round down. INT(-2.4) is −3.
FIX(n) Truncate toward zero. FIX(-2.4) is −2 — the only place it differs from INT.
SQR(n) Square root.
EXP(n) e to the n.
LOG(n) Natural logarithm.
SIN COS TAN ATN Trigonometry, in radians.
RND[(n)] A number from 0 up to but not including 1. A positive argument or none advances; 0 repeats the last one; a negative one reseeds. ✓
CINT CSNG CDBL Convert between the numeric widths. CINT rounds to nearest and must fit in 16 bits.
LEN(a$) Length.
LEFT$(a$,n) · RIGHT$(a$,n) The first or last n characters.
MID$(a$,start[,len]) A piece, counting from 1. Also assignable, replacing in place without changing the length.
INSTR([start,]a$,b$) Where b$ appears in a$, counting from 1; 0 if it does not.
CHR$(n) The CP437 character with that code.
ASC(a$) The code of the first character.
STR$(n) A number as text, with PRINT's leading sign position.
VAL(a$) The leading number in a string, or 0.
STRING$(n,c) · SPACE$(n) n copies of a character; n spaces.
UCASE$ LCASE$ Change case — A–Z only, so the rest of CP437 is left alone and the length never changes.
LTRIM$ RTRIM$ Take spaces off one end.
HEX$(n) · OCT$(n) Base 16 or 8, sixteen-bit and unsigned: HEX$(-1) is FFFF.
LBOUND(a) · UBOUND(a[,dim]) The ends of an array. Takes a name, not a value, and refuses an array that was never defined.
INKEY$ A key if one is waiting, "" otherwise. Never waits.
SCREEN(row,col) The code of the character at a cell, counting from 1.
POS(0) · CSRLIN Where the cursor is, counting from 1.
TAB(n) · SPC(n) Inside PRINT: go to a column, or emit n spaces.
TIMER · TIME$ · DATE$ Seconds since midnight, and the clock and calendar as text. RANDOMIZE TIMER is the usual seed.
FRE(0) Bytes free. Cosmetic.

Colors

COLOR takes a foreground and a background. The blinking numbers are foreground only — blink is part of the foreground attribute — so a background takes 0–15 or 32–43.

0–15 black, blue, green, cyan, red, magenta, brown, white, then the bright eight
16–31 the same sixteen, blinking
32–37 orange, chartreuse, spring green, azure, violet, rose
38–43 the same six, bright
44–55 32–43 again, blinking

The upper half of each block blinks, so the step is +16 in the first block and +12 in the second. 32+16 is a blinking chartreuse, not a blinking orange. Run colors.bas to see them.

Errors

Reported as ?SYNTAX ERROR IN 100. The numbers are Microsoft's, so IF ERR=11 means what it always meant. ✓

1 NEXT WITHOUT FOR
2 SYNTAX
3 RETURN WITHOUT GOSUB
4 OUT OF DATA
5 ILLEGAL QUANTITY
6 OVERFLOW
7 OUT OF MEMORY
8 UNDEF'D STATEMENT
9 SUBSCRIPT OUT OF RANGE
10 REDIM'D ARRAY, DUPLICATE DEFINITION
11 DIVISION BY ZERO
13 TYPE MISMATCH
15 STRING TOO LONG
17 CAN'T CONTINUE
18 UNDEF'D FUNCTION
20 RESUME WITHOUT ERROR
29 WHILE WITHOUT WEND
30 WEND WITHOUT WHILE

Also LOOP WITHOUT DO and ARRAY NOT DEFINED, which have no classic numbers of their own, and UNPRINTABLE for ERROR n with a code that has no message.

What is not Microsoft's

Everything on this page is Microsoft's except the following, which are marked in green where they appear.

DELAY Pacing, because this machine is too fast.
DOWNLOAD UPLOAD A host instead of a disk.
HELP This page.
COLOR above 31 Twelve colors IBM's numbering cannot name.

Missing on purpose: sound, PEEK and POKE, machine code, printers, and file handling. Pasting a listing does what LOAD would.
